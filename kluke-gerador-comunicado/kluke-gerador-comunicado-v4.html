Como usar o gerador

Você escreve o conteúdo; a identidade visual da Kluke já vem pronta.

1. Escreva direto no documento

Clique em qualquer texto — título, parágrafo, item de lista — e edite ali mesmo. O que você vê é exatamente o que sai no arquivo final.

2. Monte com blocos

Use os botões no fim do documento para acrescentar o que precisar. Passe o mouse sobre um bloco para ver as opções de estilo, mover e remover; arraste pelo ícone ⠿ para reordenar.

  • Texto — parágrafo comum ou destaque de abertura.
  • Lista — itens numerados.
  • Checklist — para o cliente marcar o que já reuniu. Cada item aceita uma explicação curta e a etiqueta “Se houver”, para os casos que não valem para todo mundo.
  • Linha do tempo — prazos em sequência, como cronogramas de obrigação.
  • Alerta — aviso curto em destaque âmbar.
  • Atualização — para quando uma norma muda depois de o comunicado ter saído.
  • Observação — nota de rodapé do conteúdo.

3. Salve e publique

  • Salvar HTML — gera o arquivo do comunicado. Envie para quem publica; o link é o que vai para o cliente.
  • Imprimir — abre a versão para papel ou PDF, já sem os controles de edição.
  • Copiar p/ e-mail — copia uma versão simplificada para colar no corpo de um e-mail.
  • Carregar — reabre um arquivo salvo por esta versão para editar de novo.

Nada é enviado para lugar nenhum: tudo fica no seu computador. O rascunho é salvo neste navegador enquanto você edita, mas use Salvar HTML para guardar de verdade.
